# Library Demo — Run Guide

## Prerequisites

Make sure you have Java installed on your machine.

You can check your Java version with:

```bash
java -version
```

## Run the demo

Clone your fork of the repository and move into the project directory:

```bash
git clone <YOUR_FORK_URL>
cd <PROJECT_DIRECTORY>
```

Then run the library demo using :
python3 run.py demo

## Expected result

The demo should start successfully
